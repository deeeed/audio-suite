# Farmslot recipe

This directory was generated by `@farmslot/expo-recipe`.

The files use Recipe Protocol v1, but the project-facing path and scripts are intentionally versionless so future protocol upgrades do not churn app code.

## Quality rules

- Keep the default manifest small. Add only capabilities this project actually supports.
- Prefer one parameterized domain action over many near-duplicates.
- Do not add task, ticket, or one-off debug actions to reusable manifests.
- Use UI actions only when the proof must show real user-visible interaction.
- Use commands/controllers for setup, diagnostics, and non-visual checks.
- If you declare app/HUD bridge actions, wire the dev-only bridge and run `yarn recipe:doctor`.
